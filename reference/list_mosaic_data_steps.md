# List the steps `update_mosaic_data()` knows about

List the steps
[`update_mosaic_data()`](https://institutefordiseasemodeling.github.io/MOSAIC-pkg/reference/update_mosaic_data.md)
knows about

## Usage

``` r
list_mosaic_data_steps()
```

## Value

A `data.frame` of `step`, `group`, `depends_on`, `description`. Every
listed step runs in the default plan.
